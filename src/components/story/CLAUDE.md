# STORIES — прослушивание и слайд-шоу

- **Пока без ИИ** (решение пользователя 2026-09-29): никаких нейросетевых
  дикторов и внешних TTS-сервисов. Голос истории — запись кого-то из семьи
  (аудио-медиа в приватном Blob) или, если записи нет, голос устройства
  (Web Speech `speechSynthesis`, голоса ОС). Кнопка «Слушать» — у всех
  историй. Не предлагать ИИ-диктора снова, пока пользователь сам не
  вернётся к этому.
- Запись голоса семьи — строка `media` с `kind = 'audio'`, связанная с
  историей ТОЛЬКО через `story_narration` (одна на историю, новая заменяет
  старую). Никогда не через `media_story` (это фото-карусель истории), не
  через `media_person`/`media_album`. Кто может слушать — решает история, а
  не приватность строки media (`getVisibleMedia`). Удаление истории удаляет
  и её запись.
- Плеер живёт в layout семьи (`ListeningHost`, `listen/`), не на странице
  истории: история продолжает звучать, пока читатель ходит по семье, и
  останавливается только при уходе из семьи. Страница истории лишь
  предлагает свою историю (`NarrationProvider`); вне её капсула показывает
  название истории ссылкой. Не возвращать плеер в страницу.
- Слайд-шоу в шапке истории идёт само, без кнопки ▶; его таймер — кольцо
  прогресса на кнопке «Все фото» (`carousel-film.tsx`).
